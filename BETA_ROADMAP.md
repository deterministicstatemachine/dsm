# DSM Beta Roadmap — Expected in the Next Beta Release

The initial DSM beta launches with its existing functionality, including offline transfers, trading, wallet integration, application builder, and TypeScript and Python developer clients.

The following six enhancements are targeted for the next beta release.

## Application-Level Features

1. Expanded Unique Objects
   - First-class support for uniquely identifiable assets.
   - Configurable ownership, transfer, and destruction rules.
   - Support for inventory, equipment, collectibles, and digital property.

2. Verifiable Collections
   - Cryptographically authenticated collections of objects.
   - Verifiable membership and integrity.
   - Support for inventories, registries, catalogs, and grouped assets.

3. Custom Units and Signed Schemas
   - Developer-defined units, measurements, and asset types.
   - Cryptographically signed schemas defining their properties.
   - Support for domain-specific quantities and application data.

4. Durable Signed Records
   - Persistent, cryptographically authenticated records.
   - Verifiable authorship, integrity, and record history.
   - Support for certificates, receipts, audit trails, and custody documentation.

## Core Protocol Enhancements

5. Fork-Aware Precommitments
   - Authenticated commitments to conditional state transitions.
   - Independent witness generation and verification.
   - Cryptographic verification of selected execution branches.
   - Resource-consumption and transition-validity enforcement.

6. Externally Backed Asset Enforcement
   - Protocol-level support for assets representing external resources.
   - Authenticated evidence of external backing.
   - Enforcement of defined issuance and backing constraints.
   - Support for externally backed assets and real-world custody applications.

## Release Plan

Current Beta:
Launch with existing, tested DSM capabilities.

Next Beta Release:
Target implementation of all six enhancements.

The first four features build on existing DSM cryptographic primitives.

The final two require additional Core development, security testing, and protocol verification.

All six features are planned enhancements within the beta development cycle.

Implementation and release remain subject to successful testing and verification.
