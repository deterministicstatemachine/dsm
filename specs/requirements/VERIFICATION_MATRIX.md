Derived artifact. Not a source of protocol truth; `specs/README.md` governs. Requirement IDs are those of `MASTER_REQUIREMENTS.md` §8.

**Status: partial.** Only the gates built or repaired since branch `fix/beta-skeleton-compile` (2026-09-24) are mapped below. Every name in the Negative test column is a canonical test name that `ci/conformance_evidence.py` checks exists (and, given the board logs, ran and passed). Mapping every security-critical requirement of `MASTER_REQUIREMENTS.md` to a negative test, a mutation control and a formal check is step 9 of the backend method and is owed. A requirement absent from this table has no verified mapping. That does not mean it lacks a test; it has not been checked here.

## Columns

- **Gate**: the code that enforces the requirement.
- **Negative test**: a test that attempts the forbidden action on real material and asserts the refusal.
- **Mutation control**: the gate removed or weakened, the named test observed red, the gate restored. "Not run" means the test exists but no mutation has shown it is load-bearing.
- **Formal**: a TLA+ or Lean artifact whose property is this requirement, or `—`.

Tests named `dsm_sdk::…` run on devices created as wallet creation creates them, against the storage node's own code on Postgres.
