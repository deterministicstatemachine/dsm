# TypeScript Protobuf Bindings

Source of truth: `proto/dsm_app.proto` at the repository root.

`dsm_app_pb.ts` is generated by `@bufbuild/protoc-gen-es` (pinned in `package.json`) and
committed. Do not hand-edit it; regenerate it whenever the proto changes.

## Generate

Requirements: Node.js, the frontend's `node_modules`, and `protoc` on `PATH`.

```bash
# from dsm_client/frontend
npm run proto:gen
```

`scripts/proto_gen_all.sh` at the repository root runs this and then builds the Rust bindings.

## Importing in the UI

```ts
import * as pb from './proto/dsm_app_pb';
```

The types are for transport only. Canonical encodings and every acceptance rule live in Rust.
